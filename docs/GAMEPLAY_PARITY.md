# Игровая логика: этап исправлений Beta 1.7.3

## Что реализовано

| Задача | Результат |
| --- | --- |
| Крафт | 2×2 в инвентаре, 3×3 на верстаке; 151 рецепт из неизменённого Beta JAR, отражение/смещение, shapeless, metadata и возврат вёдер после торта |
| Save and Exit | Немедленный вызов сохранения; отсутствующие Player/Time и поля игрока создаются; пустые отсутствующие Beta-чанки не мешают выходу; ошибка сохраняется на экране |
| Контейнеры | Печь: ингредиент, топливо, результат только для извлечения; 200 тиков на переплавку. Сундук: 27/54 слота, проверка блока сверху и запрет тройного сундука; содержимое выпадает при разрушении |
| Блоки | Собственные грани верстака/печи/сундука; половины двойного сундука; узкий красный факел с креплением, инверсией и burnout; кактус с поддержкой, ростом и контактным уроном |
| Портал | Анимированная плоскость, свечение и оригинальный звук; переход между измерениями отключён |
| Выживание | 20 HP, полные/половинные сердца, воздух, падение, вода/лава/огонь/кактус, смерть и возрождение. Еда сразу лечит, без современной системы голода |
| Текстуры | UV дают ровно 16 текселей на блок независимо от размера greedy-прямоугольника; исправлены перевёрнутые вертикальные грани и оттенок травы в инвентаре |
| Персонаж | Модель удалённого игрока по skin 64×32, голова и ходьба; рука и выбранный блок/предмет от первого лица; инструменты больше не рисуются камнем среди выпавших предметов |
| Копание | Извлечённые из Beta значения hardness, силы/harvest инструментов и durability; штрафы под водой/в воздухе, трещины; серверные start/cancel/finish отправляются по прогрессу |
| Жидкости | Вода: задержка 5 тиков, спад 1 до уровня 7. Лава: 30 тиков, спад 2 до уровня 6. Поиск выхода вниз, падающий поток, удаление потока без источника, объединение источников воды, реакции воды/лавы; общие высоты углов и боковые грани |
| Сохранение | Chest/Furnace TileEntities, Item Entities и поддерживаемые TileTicks сохраняются в McRegion; native миры используют NBT `.rct`. Неизвестные записи и дополнительные теги сохраняются |
| Сеть | Серверные окна игрока/верстака/сундука/печи, свойства печи, Click Window и Transaction, восстановление после отклонения клика, Respawn в том же измерении |
| Редстоун | Weak/strong power, провод через ступени, рычаг/каменная кнопка (20 тиков), повторитель с направлением и задержкой 2/4/6/8 тиков; burnout и восстановление факела через random tick |
| Кровать / погода | Две половины, сон 100 тиков, утро/сброс погоды/respawn; 24 000 тиков на сутки, Beta-климат, дождь/снег/замерзание, сохранение времени и погоды |
| Мобы / сложность | 8 типов сохранённых мобов, HP/melee/drops/звуки, ограниченное движение, стрижка/молоко/яйца; Peaceful/Easy/Normal/Hard и Peaceful healing |
| Аудио | Оригинальные эффекты с StepSound/volume/pitch, spatial sound, дождь/вода/огонь/портал; 12 оригинальных треков, streaming EOF и случайные паузы музыки |

Дальность растекания — число шагов по горизонтали, а не квадрат заполненных
блоков: вода до семи шагов от источника, лава до трёх. На плоской поверхности
получается ромб. Золотой инструмент в оригинальной Beta быстрее алмазного
(12 против 8), но слабее по прочности и допустимой добыче руды.

## Источники и устройство

`tools/ExtractBetaRecipes.java` — собственный development-инструмент чтения
реестров из установленного vanilla клиента. В runtime входят только числовые
таблицы рецептов, материалов, stack limits, durability и mining. Java и JAR
не нужны игре. Логика сверялась с Beta CraftingManager/SlotCrafting,
TileEntityFurnace/Chest, PlayerControllerSP, BlockFlowing/Fluid/Cactus и
BlockRedstoneTorch. Ссылки и границы реализации находятся также в
[архитектуре](ARCHITECTURE.md) и [матрице блоков](BETA_COMPATIBILITY_MATRIX.md).

Renderer остаётся fixed-function OpenGL 1.x. Новые блоки входят в chunk meshes;
GUI использует bitmap font и текстурные панели. Атлас 1024×1024 занимает
5 592 404 байта вместе с полной mip-цепочкой. Анимация обновляет на CPU только
видимые клетки атласа; FBO, GLSL и покадрового blur здесь нет.

## Проверки

- Windows UCRT64: сборка и 19/19 CTest; native GL и программный GL 1.1.
- Крафт: смещение, отражение, shapeless, отказ при лишнем ингредиенте, торт,
  metadata, split/merge и защищённый результат.
- Gameplay: дальность/задержки воды и лавы, исчезновение после удаления
  источника, источник из двух источников воды; печь и сундуки, их сохранение,
  выпадение содержимого, HP и инверсия факела. Вёдра собирают только источники,
  устанавливают воду/лаву и не расходуются в креативе.
- Pending ticks: оставшаяся задержка лавы после двух сохранений, выгрузки и
  повторного открытия; неизвестный tick compound сохраняется без изменений.
- NBT: неизвестная сущность и дополнительные поля Item сохраняются; отдельный
  тест level.dat без Player/Time проверяет создание полей и запись vitals.
- Renderer: одинаковая плотность/фаза UV при разных размерах объединения;
  совпадение высот поверхности воды на границе чанков и наличие боковых граней.
- Loopback protocol 14: сундук с 63 серверными слотами, rejected/accepted
  transactions, cursor resync, свойства печи и same-dimension Respawn.
- GUI: просмотрены снимки верстака, печи, большого сундука, HP и набора блоков.
- Новые проверки: ночь/погода/сон через границу чанков, сохранение старого
  native world.dat и новых environmental fields, кнопка/повторитель/dust branch,
  сложность/мобы/преграда на луче/стрижка/молоко/яйца, Java golden climate,
  музыка без loop и с паузами; снимки дождя/снега/сна/мобов.
- Оба реальных Beta-мира открывались и сохранялись только во временных копиях,
  при запуске из другой cwd. Оригинальные saves проверяются по SHA-256.

Команды воспроизведения снимков находятся в [README](../README.md). Fixtures
smoke-режима не записываются в пользовательские миры.

## Что ещё не соответствует оригиналу

Это не полный порт Beta. Нет точной генерации отсутствующих Beta-чанков,
измерений, полного redstone engine (поршни и остальные механизмы),
AI всех мобов, полной боевой/броневой системы и всей логики предметов.
Часть блоков всё ещё имеет proxy-геометрию. Портал пока не создаётся зажигалкой
и не проверяет целостность рамки. Sand/gravel перемещаются к месту падения без
анимации FallingSand entity. Большие redstone circuits ограничены бюджетом
scheduled ticks. Есть skylight subtraction и климат осадков, но полное sky,
biome tint, генерация и освещение всех collision shapes ещё неполные.

Подробный статус сна, NPC, погоды, режимов, сложности, звуков, музыки и
оставшихся задач находится в [аудите механик](BETA_MECHANICS_AUDIT.md).

Сетевые проверки используют mock server; они не доказывают полную совместимость
с настоящим сервером. Native Snow Leopard/i386 и реальный GMA 950 требуют
отдельной сборки и измерений. Session.lock token теперь проверяется перед
записью; это механизм Beta для обнаружения другого opener, а не OS-lock
полной транзакции нескольких файлов.
