# Аудит механик Minecraft Beta 1.7.3

Проверка от 2 октября 2026 года. Целевая версия — vanilla Beta 1.7.3,
protocol 14, Overworld высотой 128 блоков. Этот документ описывает текущий
код и проверки; полная совместимость с Beta пока не достигнута.

## Изменённые системы

- `world/environment.c`: часы, погода и skylight subtraction. Значения SkyLight
  в NBT остаются дневными; mesh обновляется при смене целого уровня яркости.
  Сон переводит также очередь scheduled ticks к рассвету; возраст сущностей
  не увеличивается на пропущенную ночь.
- `world/climate.c`: воспроизведение исходного 2D-климата. В чанке кешируются
  вид осадков и высота крыши; высота пересчитывается после изменения блоков.
- `renderer/weather.c`: два texture batch, радиус 5 для Fast / 10 для Fancy,
  depth test и обычный alpha blending. Нет FBO, GLSL или blur для осадков.
- `game/bed.c`: две половины, сон/пробуждение/respawn. Player SpawnX/Y/Z
  отделены от мировых Data.SpawnX/Y/Z.
- `world/redstone.c`: направления weak/strong power и компоненты. Очередь
  ограничена бюджетом; большой circuit может требовать дополнительных тиков.
- `world/mobs.c`: общая ограниченная симуляция сохранённых мобов. Обрабатываются
  до 128 мобов в радиусе 32, рисуются до 64; это явное ограничение legacy-клиента.
  Луч выбора ограничен настоящей гранью блока, а не его центром.
  Движение проверяется промежуточными шагами, включая формы кроватей/полублоков;
  моб не переходит в незагруженный чанк и не проскакивает тонкий пол при падении.
- `audio/sound_policy.c`, `beta_block_sounds.def`: материальные звуки и
  политика пауз музыки; `audio.c`: 16 переиспользуемых OpenAL voices.
  Ambience использует условия randomDisplayTick, не постоянные циклы.
- `audio/music_stream.c`: существующий stb_vorbis и четыре маленьких OpenAL
  buffers. Полные треки не декодируются в RAM; EOF дожидается последних samples.
- `assets/runtime_assets.txt`: единый allowlist для CMake, GNU make и CI package.
  Текстуры CoterieCraft не перезаписаны; звуки/музыка скопированы побайтно из
  read-only установленной инстанции. Runtime не обращается к ней или third_party.

Native `world.dat` RCW1/v2 хранит время/погоду; v1 читается с прежними defaults
и обновляется при сохранении. Native `player.txt` v3 добавляет координаты
кровати, v1/v2 читаются. Для Minecraft сохраняются оригинальные поля level.dat
и Entity NBT. Неизвестные теги сохраняются, incomplete mob compounds остаются
неизменёнными. Оригинальные пользовательские saves в тестах не записываются.
Interactive Beta play также получает session.lock token и проверяет его при
сохранении/выгрузке dirty chunk. Чужой, пропавший или повреждённый token
блокирует запись; это advisory-схема Beta, не OS-lock всей транзакции.

## Очередь оставшейся реализации

1. Beta ChunkProviderGenerate/population: отсутствующие `.mcr` chunks сейчас
   остаются пустыми. Нужны Java golden chunks и сравнение seed/blocks/metadata.
2. Естественный спавн/despawn и поиск пути мобов; Skeleton arrows, Creeper
   fuse/explosion, Slime/Squid/Wolf и прочие Beta-сущности. Ночные нападения
   при сне должны подключаться к этой же системе.
3. Броневые слоты/износ/формула защиты, knockback и полная модель combat.
4. Поршни со moving TileEntity и ограничением 12 блоков, pressure plates,
   redstone-двери/люки, dispensers, rails, TNT, jukebox/note blocks.
5. Молнии и их последствия, огонь с распространением/дождём, таяние снега/льда,
   растения/фермы, все действия предметов и полный набор collision shapes.
6. Серверные entity status/sleep/equipment, Shift-click контейнеров и проверки
   настоящим protocol 14 сервером. Mock session не доказывает interoperability.
7. Native Snow Leopard/i386 и GMA 950: сборка и измерение времени тика/рендера
   на целевом компьютере; Windows RTX 3060 не заменяет эту проверку.

## Проверки

Windows UCRT64: **19/19 CTest**, в том числе native GL и software GL 1.1.
Дополнительный `-std=c99 -Wall -Wextra -Wshadow -fsyntax-only` для изменённых
модулей — без diagnostics. Покрыты крафт, печь, сундуки, жидкость, pending
ticks, ночь/дождь/сон через границу чанков, respawn, сложность, кнопка/повторитель,
направление dust branch, удар за стеной, стрижка/молоко/яйца, mob NBT,
падение моба на тонкий пол и перенос между загруженными чанками,
old native metadata и Time Update/Begin Rain по loopback protocol 14.
Отдельный session test и fixture-проверки подтверждают отказ записи region и
level.dat при смене владельца, с неизменёнными hashes исходной копии.
Исправлен подсчёт последнего отрезка падения до поверхности: падение с 3.2
блока наносит 1 HP. Повторная сборка не изменила 102 SHA256 пользовательских
save-файлов. Оба Beta-мира открыты/сохранены на копиях при запуске из другой cwd.
Runtime package содержит ровно 130 файлов manifest, без saves и reference files.

`climate_test` проверяет оригинальные Java golden values; `sound_policy_test`
проверяет материальные ключи и остановку countdown; `music_stream_test` —
неповторяющийся EOF и освобождение stream (OpenAL Soft null driver).
Снимки `day`, `night`, `rain`, `snow`, `bed`, `mobs` доступны через
`--smoke-test --screen NAME --capture PATH`. `snow` принудительно задаёт
снежный климат только in-memory fixture; climate проверяется отдельным тестом.
