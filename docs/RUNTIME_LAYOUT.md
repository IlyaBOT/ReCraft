# Source and runtime layout

The source tree keeps C99 modules in `src/`, checks in `tests/`, documentation
in `docs/`, normalized source media in `assets/`, and dependency/reference
material in `third_party/`. Build objects and deployed files live in ignored
`build/`. The CMake object tree is `build/windows-ucrt/`; GNU make objects are
`build/legacy/`.

The game directory is the directory containing `ReCraft.exe` on Windows and
the directory containing `ReCraft.app` on macOS. By default both are `build/`:

```text
build/
  ReCraft.exe                 (Windows development build)
  ReCraft.app/               (macOS i386 build)
  assets/                    (selected deployed files; generated by the build)
    fonts/ascii.png
    gui/background.png, icons.png, inventory.png, items.png, panorama.png, widgets.png
    textures/terrain.png
  saves/                     (persistent ReCraft and Beta worlds)
  texturepacks/              (legacy Beta pack interface)
  resourcepacks/             (reserved for later versions)
  shaderpacks/               (directory/interface only)
  screenshots/                (F2 PNG captures)
  logs/
  config/options.txt, servers.txt
  crash-reports/
```

`mods/` is reserved and deliberately not created. No mod loader or shader
system exists. The current renderer consumes built-in deployed assets; custom
texture pack selection is future work. The installed Beta 1.7.3 Minecraft
instance was used only to compare directory structure and was not changed.

The game root comes from `game_executable_root()` in `src/util/game_paths.c`
using `GetModuleFileNameA` on Windows, `_NSGetExecutablePath` and `realpath` on
macOS, and `/proc/self/exe` on Linux. `--data-dir` overrides the entire root.
`assets_path()` resolves resource IDs within it. Neither resource lookup nor
save discovery relies on the process working directory. The build deploys only
known asset files and never clears `saves/`.

World selection combines ReCraft `world.dat` saves with Beta `level.dat`
metadata discovery. Beta saves can have spaces in directory names. The
detector reads seed, name, spawn, time, player position and `.mcr` region count.
Play opens existing Beta `.mcr` chunks. Loaded-chunk block edits are persisted
to the region files, preserving other NBT tags. ReCraft stores its player and
inventory changes in `player.txt` and `inventory.txt` beside `level.dat`; the
original player NBT is read on first open. World deletion stays disabled for
Beta entries. Missing Beta chunks are left empty rather than generated with
ReCraft terrain. Read-only tests use the supplied worlds; write tests use a
copy of a region file.

The video screen defaults to VSync at the detected monitor refresh rate.
Manual caps cycle through 25, 30, 50, 60, 75, 90, 120 and 144 FPS, showing
only values no greater than the monitor refresh. The window backend handles
VSync; a CPU sleep applies manual caps. The 20 Hz game tick remains separate,
with camera position interpolated for rendering. Fullscreen uses a monitor-size
window without changing the display mode or replacing the GL context on
Windows; other platforms resize the existing window to the monitor bounds.
