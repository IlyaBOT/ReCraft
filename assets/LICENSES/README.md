The runtime uses selected user-provided CoterieCraft Beta textures and an
original Minecraft bitmap font atlas. `assets/metadata/pack.txt` records the
pack description reconstructed from the pre-migration audit; exact original
bytes are unverified. It does not provide a redistribution license. These
files were supplied for local development; check rights before publishing a
binary or media archive. See `docs/ASSET_SOURCES.md` for the exact file map.
